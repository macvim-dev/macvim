Updated to Vim 9.2.1252

This release mostly brings the Vim version up to date.

Announcements
====================

Moving macOS 10.13 - 11.0 support to legacy release
--------------------

The next binary release of MacVim will require macOS 12.0 Monterey or above for the normal version. Users of macOS 10.13 - 11.0 will need to use the legacy version instead. If you are updating MacVim via the builtin updater, this should work automatically. For the most part this should be a transparent change for those users, except for an older updater (Sparkle 1).

Note that the last MacVim release made a similar announcement but we never ended up bumping the min requirement.

General
====================

- Sparkle (updater for MacVim) is now updated to 2.9.6. #1702

New Vim Features
====================

- Modeline now defaults to a limited subset of whitelisted options (`:h 'modelinestrict'`). v9.2.0350
    - Note: This change is slightly backwards incompatible. If you want to open files with modelines using non-whistlisted options, you will need to turn it off by adding `:set nomodelinestrict` to your vimrc.
- Popup images (`:h popup-image`). This works in terminals that support displaying images. MacVim will support this in a later version. v9.2.0612
- new bundled color scheme:
    - novum, port of Neovim's dev_theme (vim/vim#20723)
- Clickable regions in the statusline, tabline and tabpanel with the new %[FuncName] item.
- Misc tab panel and tab line improvements.
- Fixes the stray "pp" that shows up when opening Vim in terminal. v9.2.0389
- Misc performance improvements and security fixes.
- Other platforms (these don't affect MacVim and included for reference only):
    - Support for GTK 4 on Linux. v9.2.0501


Compatibility
====================

Requires macOS 10.9 or above. (10.9 - 10.12 requires downloading a separate legacy build)

Script interfaces have compatibility with these versions:

- Lua 5.5
- Perl 5.34
- Python2 2.7
- Python3 3.9 or above
- Ruby 4.0
